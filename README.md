## 🚀 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/muzamilCodes/War-Muzamil.git
cd War-Muzamil
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Build for Production
```bash
npm run build
```
